# Leisure · 闲暇推理社

手机与电脑浏览器均可玩的中文逻辑解谜小游戏。第一案「咖啡馆的四位客人」以人物头像、饮品插画和箭头关系呈现六条线索。点座位即可选图，提供分步图解提示、答案检查和本机进度保存。错误摆放会用橙色标出不符合的线索。

## 手机游玩

GitHub Pages 开启并部署完成后，用手机浏览器访问 https://jokiaaa.github.io/Leisure/ 。看六张线索卡，再点座位上的「＋客人」「＋饮品」选择图示，最后点「验证答案」。点线索卡可标记已用，点「图解提示」可查看分步推导。

## 本地运行

无需安装前端依赖。在仓库目录运行：

```sh
python3 -m http.server 8000
```

在浏览器访问服务器的 8000 端口。手机访问需要与服务器网络互通；公开使用可将 `index.html`、`style.css`、`visuals.js`、`app.js` 部署到静态网站托管服务。GitHub Pages 设置入口为仓库的 Settings → Pages，选择从 main 分支根目录部署。

## 文件

- `index.html`：页面与案件说明
- `style.css`：手机及桌面响应式布局
- `visuals.js`：内联 SVG 人物、饮品和线索图示，无外部图片请求
- `app.js`：选图交互、线索、答案验证、提示和本机存档

进度通过浏览器 localStorage 保存；清理网站数据会删除进度。当前提供一个固定案件，无后端、账号或外部接口。

## 验证

```sh
node --check app.js
node --check visuals.js
```
