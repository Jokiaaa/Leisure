# Leisure · 闲暇推理社

手机与电脑浏览器均可玩的中文逻辑解谜小游戏。第一案「咖啡馆的四位客人」包含六条线索、座位与饮品推理、分步提示、答案检查和本机进度保存。

## 本地运行

无需安装前端依赖。在仓库目录运行：

```sh
python3 -m http.server 8000
```

在浏览器访问服务器的 8000 端口。手机访问需要与服务器网络互通；公开使用可将 `index.html`、`style.css`、`app.js` 部署到静态网站托管服务。当前未部署公开网址。

## 文件

- `index.html`：页面与案件说明
- `style.css`：手机及桌面响应式布局
- `app.js`：线索、答案验证、提示和本机存档

进度通过浏览器 localStorage 保存；清理网站数据会删除进度。当前提供一个固定案件，无后端、账号或外部接口。

## 验证

```sh
node --check app.js
```

另已使用 Chromium 自动化验证完整答题流程、错误答案、重复选择、提示、刷新恢复、重置，以及 375 / 390 / 768 / 1280 像素视口无横向溢出。谜题经穷举 576 种组合确认具有唯一解。
